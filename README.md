# WorkLog（作業ログ自動記録）

PC で今どのアプリ・どのプロジェクトを触っているかを自動で記録し、
「今日は何に何分使ったか」「どのプロジェクトを放置しているか」を見られる Windows 常駐アプリです。

- C# / .NET 8 / WinForms、自己完結型の単一ファイル exe（.NET のインストール不要）
- 記録はこの PC の中だけに保存し、外部には一切送信しません

## インストール方法

1. [Releases](../../releases) を開き、最新の `WorkLog-vX.Y.Z.exe` をダウンロードする
2. 好きなフォルダ（例：`C:\Tools\WorkLog\`）に置いてダブルクリック
   - 初回は「Windows によって PC が保護されました」と出ることがあります（署名なしのため）。「詳細情報」→「実行」で起動できます
3. タスクトレイに丸いアイコンが出れば記録中です

自動で起動したい場合は、トレイの右クリック →「設定」→「Windows 起動時に自動で開始する」をオンにしてください。
exe を別の場所に移動したり新しいバージョンに差し替えたりしたら、もう一度設定を開いて「保存」を押すと登録先が更新されます。

**更新するとき**：トレイから「終了」→ 新しい exe に差し替えて起動。データはそのまま引き継がれます。

## 使い方

| 操作 | 内容 |
|---|---|
| トレイアイコンを左クリック | 今日のまとめを開く |
| 右クリック | 今日のまとめ／一時停止・再開／放置プロジェクト／CSV出力／設定／終了 |
| `Ctrl` + `Alt` + `P` | 記録の一時停止・再開 |
| マウスを乗せる | 今日の合計作業時間と、今日いちばん長いプロジェクト |

アイコンの色：**緑**＝記録中、**灰色**＝離席中（3分以上操作なし）、**黄色**＝一時停止中

## データの保存場所

すべて `%APPDATA%\WorkLog\`（通常 `C:\Users\<ユーザー名>\AppData\Roaming\WorkLog\`）に保存されます。
エクスプローラーのアドレス欄に `%APPDATA%\WorkLog` と入力すると開けます。

| ファイル | 内容 |
|---|---|
| `logs\YYYY-MM-DD.json` | 1日1ファイルの作業記録（開始・終了時刻、アプリ名、ウィンドウタイトル、プロジェクト名） |
| `projects.json` | プロジェクトの判定ルール |
| `settings.json` | 設定（離席判定の分数、放置日数、除外アプリなど） |
| `error.log` | エラーが起きたときだけ書かれるログ |

- 記録中のデータは30秒ごと・スリープ時・シャットダウン時に保存されます（強制終了しても失うのは最大30秒分）
- JSON が壊れていた場合は削除せず `*.broken-日時` という名前で退避してから新しく作り直します
- バックアップしたいときは `%APPDATA%\WorkLog` フォルダごとコピーしてください

## プロジェクトの登録方法

トレイの右クリック →「設定」→「プロジェクト」タブ →「＋ 新しいプロジェクト」。

- **プロジェクト名**：まとめ画面に表示される名前
- **キーワード**：1行に1つ。ウィンドウタイトルにキーワードが含まれていれば、どのアプリでもそのプロジェクトとして記録します（大文字・小文字は区別しません。長いキーワードが優先）
- **完成済み**：オンにすると放置プロジェクト一覧に出なくなります

自動判定のルール：

| アプリ | 判定方法 |
|---|---|
| どのアプリでも | タイトルに登録キーワードが含まれる → そのプロジェクト |
| VS Code | `ファイル名 - フォルダ名 - Visual Studio Code` のフォルダ名 |
| Unity | タイトル中のプロジェクト名 |
| それ以外 | 「その他（アプリ名）」として集計 |

VS Code のフォルダ名・Unity のプロジェクト名が、登録したプロジェクト名かキーワードと一致すれば、登録名にまとめられます。

> **ブラウザの注意**：Chrome / Edge のタイトルには URL が入りません。`github.com/ferrarissound-design/xxx` ではなく、
> GitHub のページタイトルに出る `ferrarissound-design/xxx` のような文字をキーワードにしてください。

`projects.json` を直接編集することもできます（アプリが1分以内に読み直します）：

```json
{
  "version": 1,
  "projects": [
    { "name": "ジョークラ", "keywords": ["joukura", "ジョークラ"], "completed": false },
    { "name": "ジョーダンジョン", "keywords": ["jo-dungeon"], "completed": false }
  ]
}
```

知らない項目（将来のプロジェクトランチャー用の項目など）を追加しても、WorkLog は消さずに残します。

## プライバシーと除外設定

- 「設定」→「除外アプリ」に登録したアプリ（初期値：LINE、KeePass、KeePassXC、1Password、Bitwarden）は、
  アプリ名もタイトルも保存せず「除外」とだけ記録します
- 登録するのはプロセス名（タスクマネージャーの「詳細」タブの名前から `.exe` を除いたもの）です
- 他人に見られたくない作業中は `Ctrl` + `Alt` + `P` で一時停止できます

## CSV 出力

トレイの右クリック →「CSV出力…」で期間を指定すると、`日付,プロジェクト,分数` の CSV を書き出します（UTF-8 BOM 付きで Excel でそのまま開けます）。

## 開発者向け

- ソース：`src/WorkLog/`
- push するたびに `Build` ワークフローがビルドし、Actions の Artifacts から試用版 exe を落とせます（7日間保存）
- リリース：Actions タブ →「Release」→「Run workflow」→ バージョン（例 `1.0.0`）を入力。
  `v1.0.0` タグと GitHub Release が作られ、`WorkLog-v1.0.0.exe` が添付されます。同じタグがあればエラーで止まります
